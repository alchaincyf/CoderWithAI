## 一句话
大模型（LLM）是用海量文本训练出来的AI。它的核心本领是：看到一段文字后，预测接下来最合理的内容。回答问题、写代码、翻译，都是这一个本领的不同用法。

## 打个比方
像一个读遍了图书馆的人，你问什么，他都能顺着已有的知识接着说。

不贴切的地方：他不是在「查资料」，而是在「凭印象接话」。所以会说得很流畅，但也可能错得很自信，见[幻觉](/words/hallucination)。另外他没有长期记忆，每次对话是新的，只记得[上下文窗口](/words/context-window)里的内容。

## 你会在哪儿碰到它
- 你用的ChatGPT、Claude、Gemini、DeepSeek、通义千问、豆包，背后各有自己的模型，同一家也分大小、新旧不同版本。
- 在Claude Code里用`/model`可以切换模型。
- 做产品要调用模型时，会通过[API](/words/api)，按[Token](/words/token)计费。
- 常见词：模型版本号、「推理模型」「开源模型」，分别指带思考过程的、可以下载自己运行的。

## AI提到它时，你该怎么接
选模型是在「聪明程度、速度、价格」之间取舍。

```prompt 复制给 Claude Code
我要做一个「帮用户把长文章总结成三句话」的小功能，每天大概几百次调用，预算很有限。
请帮我选模型：给出两三个候选，各自的优缺点和大致费用（请查官方定价页，不要凭记忆），并推荐一个。写一个最小的调用示例，先用10篇文章测试质量，再决定要不要换更便宜的。
```

## 容易踩的坑
- 把模型的话当事实：涉及价格、版本、数据、法规，要让它给出处并自己核对。
- 以为模型认识你的项目：它只知道你给它看的内容，所以要靠[AGENTS.md](/words/agents-md)这类说明书让它了解。
- 只看跑分选模型：适合自己任务、价格能接受的才是好模型。
- 国内外服务可用性、付款方式不同，接入前确认能不能稳定使用。
