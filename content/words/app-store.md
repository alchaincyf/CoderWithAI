## 一句话
上架App Store，就是通过苹果的开发者计划，把你的App提交审核，审核通过后全球（或指定地区）用户都能下载。

## 打个比方
像把产品放进大型连锁超市。你得先注册成供应商（开发者账号），商品要通过质检（审核），摆上货架后超市还分走一部分销售额。

不贴切的地方：超市质检看商品，苹果还会看你的隐私说明、内购方式、截图是否真实，被拒是常事，改了重交就行。

## 你会在哪儿碰到它
- 先加入Apple Developer Program。官方页面写明年费99美元（实际以所在地区的报名页显示为准）。个人开发者需用真实姓名，这个名字会显示为App Store上的卖家名；以公司名义要有邓白氏编码（D-U-N-S）、公司域名邮箱和可访问的官网。
- 在[Xcode](/words/xcode)里打包上传，在App Store Connect网页后台填写名称、截图、描述、隐私政策网址。
- 上架中国大陆区还涉及App备案，以苹果开发者网站和工信部的最新要求为准，见[备案](/words/icp-filing)。
- 先通过[TestFlight](/words/testflight)内测，再提交正式审核。

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
我准备把这个iOS App提交App Store审核。请帮我做一次上架前检查清单，查苹果官方的App Review Guidelines后，逐条对照我的项目：
1. 有没有需要隐私政策网址、账号删除功能、权限用途说明；
2. 有没有数字内容销售（会涉及苹果内购规则）；
3. 截图、图标、描述需要准备哪些尺寸；
4. 列出最可能被拒的三点，并给出整改建议。
```

## 容易踩的坑
- 隐私政策页面打不开或缺失、App里要登录却没提供测试账号：很常见的被拒原因。
- 在App里销售数字内容却绕开苹果内购：多数情况违反规则，见[在线收款](/words/payment)。
- 功能太单薄像网页壳：容易被拒，要有真正的原生体验。
- 开发者账号用错身份：个人账号以后转公司主体较麻烦，想清楚再注册。
- 审核时间不固定，别把发布日期卡死。
