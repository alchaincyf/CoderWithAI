## 一句话
提示词就是你发给AI的那段话：要做什么、给什么材料、做到什么算完成。写得具体，AI就做得对。

## 打个比方
像给装修师傅交代活儿。「弄得好看点」和「客厅墙刷成浅灰，踢脚线保持白色，周五前完成，完工我来验收」，得到的结果天差地别。

不贴切的地方：师傅会当面追问细节，AI常常直接开干。所以需要你一开始把话说完整，或让它先提问再动手。

## 你会在哪儿碰到它
- 你在输入框里写的每一句话，都是提示词。
- 本站的`prompt`卡片：右上角能一键复制，粘贴给AI用。
- 还有「系统提示词」，是软件开发者预先写好、用户看不到的那部分设定，[AGENTS.md](/words/agents-md)就是一份写给AI的长期提示词。

## AI提到它时，你该怎么接
好提示词的骨架：背景、目标、限制、验收标准。

```prompt 复制给 Claude Code
背景：这是一个个人记账网页，用Next.js做的，目前只有首页。
目标：新增「本月支出」页面，按分类显示金额。
限制：不要引入新的第三方库；沿用首页的样式；不要改动现有页面。
验收：我能在页面看到至少3个分类的金额；数据来自现有的expenses表；页面在手机宽度下不会横向滚动。
开始之前，如果有信息不足，先问我，不要猜。
```

## 容易踩的坑
- 只说「做得好看一点」：没有标准，每次都是赌。给参考图或具体描述。
- 一次提十件事：容易漏、容易互相冲突。拆成小步，每步验收。
- 没说不要动什么：AI会顺手重构你没让它碰的地方。
- 不要求验证：加上「做完请自己运行检查，并告诉我怎么验证」，能挡掉一半的低级问题。
- 想让AI先想清楚再写，可以先用[计划模式](/words/plan-mode)。
