## 一句话
每个主流浏览器都自带「开发者工具」。按下快捷键就能打开，看到这个网页背后发生的一切：报错、请求、代码结构。

## 打个比方
汽车的引擎盖。平时盖着，开车的人用不着；一旦哪里不对劲，掀开就能看到发动机在干什么。

不贴切的地方：引擎盖下有些东西碰不得，开发者工具里你可以放心地看，也可以临时改，但刷新后一切恢复，不会改动真实网站。

## 你会在哪儿碰到它
- 打开方式：F12，或 Mac 上 Command+Option+I，或在页面上右键选「检查」。
- 常用的几个标签页：
  - Console（控制台）：红色报错、打印出来的信息都在这里。
  - Network（网络）：页面发出的每一次请求，哪个失败了、状态码多少。
  - Elements（元素）：页面的 HTML 结构和样式，能点选看某块是什么。
- 网页空白、按钮没反应、图片不显示，AI 常说「看一下控制台有没有报错」。
- 报错里 Failed to load resource 后面带 404，是资源找不到；500 是服务器出错。

## AI提到它时，你该怎么接
```prompt
页面是空白的。请教我打开浏览器控制台，告诉我应该点哪个标签页、找什么颜色的信息。我会把看到的内容复制给你。
```

```prompt
我在 Network 标签里看到一个请求是红色的，状态码是（填写），请求地址是（粘贴）。请告诉我这是什么意思，是前端的问题还是后端的问题。
```

## 容易踩的坑
- 控制台打开了却看不到信息：可能被筛选了，检查顶部过滤器，确保显示 Errors。
- 在控制台里粘贴陌生人给的代码并运行。这是常见诈骗手段，能偷走登录状态。只运行你明白、AI 解释过的内容。
- 在开发者工具里改了样式，刷新就没了，别以为已经改好了。
- 换了浏览器、开了插件，报错内容可能不同。排查时可用无痕窗口。
