## 一句话
API是软件之间约定好的沟通方式：我按这个格式发请求，你按那个格式给回复。你让网页调用天气、地图、AI模型，用的都是API。

## 打个比方
像餐厅的点单窗口。你不用进后厨，只要照菜单说「一份宫保鸡丁」，窗口递出来的就是成品。菜单就是API文档，能点什么、怎么点，都写在上面。

比方不到位的地方：真实的API还要「验明身份」（通常要[密钥](/words/api-key)），还会限制你点单的频率。

## 你会在哪儿碰到它
- 你说「调用DeepSeek / OpenAI /天气服务」，AI会说「调用它的API」，并让你去申请Key。
- 代码里出现`fetch("https://api.xxx.com/...")`、`/api/chat`这样的路径、`GET`/`POST`。
- 浏览器[开发者工具](/words/devtools)的Network标签，能看到网页发出的每一个请求。
- 返回的内容大多是[JSON](/words/json)。

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
我想在网页里调用某个第三方服务的API，文档在：<粘贴文档链接>。
请先用不超过5句话告诉我：它需要什么认证、一次请求长什么样、有没有调用次数限制或收费。
然后写一个最小的调用，先在终端里跑通并把真实返回结果贴给我看，再接进页面。密钥放进.env，不要写死在代码里。
```

## 容易踩的坑
- 把密钥放在前端代码里：任何人打开开发者工具就能看到。需要密钥的调用，应该由自己的服务端去发。
- 不看限额与计费：循环调用或被人刷接口，账单会涨。让AI加上频率限制。
- 请求跑得通，不代表字段对：先看真实返回的[JSON](/words/json)，再写代码，别让AI凭印象猜字段名。
- 浏览器里调第三方接口报红字，常常是[跨域（CORS）](/words/cors)，不是你写错了。
