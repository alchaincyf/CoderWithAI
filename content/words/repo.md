## 一句话
仓库（repo）就是一个被[Git](/words/git)管理起来的项目：当前的所有文件，加上过去每一次改动的历史记录。

## 打个比方
像一本带修订记录的文档，不只是最新的内容，每一页的每次改动都留着。

不贴切的地方：文档的修订记录是附在文件里的，仓库的历史藏在一个隐藏文件夹 `.git` 里，复制文件夹时别漏掉它。

## 你会在哪儿碰到它
- 本地仓库：电脑上带有 `.git` 的项目文件夹。
- 远程仓库：[GitHub](/words/github)等网站上的那一份，通常有个网址，例如 `https://github.com/你的用户名/项目名`。
- AI会说「克隆这个仓库」「新建一个仓库」「fork一下」。克隆就是把别人的仓库完整下载到本地：

```bash
git clone https://github.com/用户名/项目名.git
```

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
请帮我把当前项目变成一个GitHub私有仓库并推送上去：
1. 先检查.gitignore，确认没有密钥会被上传；
2. 仓库设为私有（private），名称叫 my-project；
3. 推送后告诉我仓库网址，并教我如何确认线上的内容和本地一致。
如果需要我先登录GitHub，请告诉我最简单的登录方式。
```

## 容易踩的坑
- 公开还是私有：新建时默认值可能是公开。含个人信息或还没想好开放的项目，先选私有。
- 仓库太大：把视频、模型、`node_modules` 提交进去，克隆和上传都会很慢。大文件让AI帮你排除或换方式存。
- 文件夹被移动、`.git` 被删：历史记录就没了。
- 国内访问GitHub可能不稳定，克隆失败时先检查网络，不要急着重装。
