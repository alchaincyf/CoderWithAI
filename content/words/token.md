## 一句话
Token是大模型读写文字时的最小切分单位，可能是一个词、半个词或一个汉字。模型的用量、速度和费用，都按Token计算。

## 打个比方
像按字数计费的翻译，但「字」不是你理解的字，而是模型自己切的小块。

不贴切的地方：每家模型切法不同，同一句话在不同模型里Token数不一样；中文一个汉字常常占一个到两个Token，英文一个单词常常约一个，只能当大致参考。

## 你会在哪儿碰到它
- 用[API](/words/api)调用模型：账单按输入Token和输出Token分别计价，输出通常更贵，具体价格以各家官方定价页为准。
- 在Claude Code里输入`/usage`查看当前会话和套餐用量。
- 提示「达到上下文上限」「session limit」，都和Token消耗有关。
- 文档里说「最大输出4096 tokens」，指一次最多能写多长。

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
我想估算这个功能每月的AI调用成本。
请查官方定价页拿到当前价格（标注查询日期），按下面假设算：每次请求输入约2000字、输出约500字，每天1000次。
给出一个公式和结果，并告诉我降低成本最有效的三种办法（比如缩短输入、换小模型、缓存结果）。
```

## 容易踩的坑
- 把Token当成字数：估费用要预留余量。
- 在对话里塞整个大文件反复问：每一轮都会重新带上之前的内容，用量滚雪球。Claude Code里换任务时用`/clear`开新会话。
- 订阅用户和API用户计费不同：订阅有使用窗口和额度，API是按量付钱，别混着算。
- 没设用量上限：程序出bug循环调用，账单会让你吃惊。
