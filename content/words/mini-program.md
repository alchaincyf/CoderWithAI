## 一句话
微信小程序是运行在微信里的应用：扫码或搜索就能用，不用到应用商店下载。国内用户多时是很自然的选择。

## 打个比方
像商场里的快闪店。顾客不用出商场、不用办会员卡，走过去就能买；但店面规矩由商场（微信）定。

不贴切的地方：快闪店可以随意装修，小程序必须遵守微信的类目、审核和开发规范，代码也不是普通网页，要用微信自己的框架。

## 你会在哪儿碰到它
- 在微信公众平台（mp.weixin.qq.com）注册小程序账号，在「设置-开发设置」里拿到AppID。
- 用「微信开发者工具」写代码、预览、上传；然后在后台提交审核。官方说明，审核通过后需要你手动点击发布，才会真正上线。
- 主体类型有个人、企业（含个体工商户）、政府、媒体、其他组织。个人主体不支持微信认证，所以做不了微信支付等一些高级能力。
- 联网请求的域名要在后台配置为合法域名，需要HTTPS，且通常要完成[备案](/words/icp-filing)。

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
我要做一个微信小程序，功能是「记录每天喝水量并显示本周统计」。我是个人开发者，没有营业执照。
请先告诉我：1.个人主体下能做什么、不能做什么（查微信官方文档）；2.需要我在微信公众平台手动做哪几步；3.用原生还是用uni-app等框架更适合我，说明理由。
我同意方案后，你生成项目，并告诉我怎么在微信开发者工具里导入预览。
```

## 容易踩的坑
- 个人主体想收钱：不行。需要个体工商户或企业主体并完成认证，具体条件以微信官方说明为准，见[在线收款](/words/payment)。
- 在小程序里调用自己服务器：域名没备案、没配置合法域名，真机上就请求失败，开发者工具里却能正常，因为那里可以关闭校验。
- 类目选错或功能与类目不符，审核会被拒。
- 提示词里别让AI用网页写法：小程序不能直接用`window`、`document`这类浏览器能力。
