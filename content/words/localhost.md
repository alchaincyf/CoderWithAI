## 一句话
localhost 是一个特殊的网址，意思是「这台电脑本身」。你在浏览器里输入 http://localhost:3000，打开的是自己电脑上正在运行的项目。

## 打个比方
像在自己家里试菜：只有家里人能吃到。localhost 就是你家的门牌，别人拿着这个门牌去，找的是他们自己的家。

不贴切的地方：门牌号是别人看得懂的，而 localhost 对别人来说毫无意义，因为它永远指向「正在访问的那台电脑」。

## 你会在哪儿碰到它
- 运行 npm run dev 后，终端会打印：Local: http://localhost:3000，点它或复制到浏览器就能看到项目。
- 数字 127.0.0.1 与 localhost 是同一个意思。
- 冒号后面的数字是[端口](/words/port)。
- 把这个链接发给朋友，他打不开。要让别人看到，需要[部署](/words/deploy)到[服务器](/words/server)上。
- 同一个 Wi-Fi 下的手机，想看电脑上的项目，需要用电脑的局域网 IP，而不是 localhost。

## AI提到它时，你该怎么接
```prompt
我想用手机看到电脑上正在开发的网页，手机和电脑连的是同一个 Wi-Fi。请告诉我怎么做，需要改什么，以及这样做有什么安全注意事项。
```

```prompt
我打开 http://localhost:3000 显示「无法访问此网站」。请帮我检查：开发服务器是否在运行、端口是否对、有没有报错。每检查一项告诉我结果。
```

## 容易踩的坑
- 开发服务器没启动，或终端窗口被关了，浏览器就打不开。
- 把 localhost 地址填进需要「公网地址」的地方，例如支付回调、[Webhook](/words/webhook)。对方的服务器访问不到你的电脑。需要时让 AI 介绍内网穿透这类临时办法。
- 端口变了，书签里的旧地址打不开。启动日志里会显示实际用的地址。
- 把 localhost 写死在代码里，上线后就会连错，应该用[环境变量](/words/env-var)。
