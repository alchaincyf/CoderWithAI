## 一句话
HTTPS 是加密版的网页访问方式。网站要有一张 SSL（准确说是 TLS）证书，才能启用它。没有，浏览器会提示「不安全」。

## 打个比方
寄信。HTTP 像寄明信片，路上谁都能看；HTTPS 像把信装进封好的信封，只有收信人能拆。证书则是邮局发的认证，证明这个信箱确实属于它声称的主人。

不贴切的地方：信封保护的是路上的内容，不保证寄信的人本身诚实。有小锁的网站，不等于它可信。

## 你会在哪儿碰到它
- 网址以 https:// 开头，地址栏有小锁。以 http:// 开头的，浏览器会提示「不安全」。
- 用 [Vercel](/words/vercel) 这类平台，绑定[域名](/words/domain)后，证书自动申请、自动续期，不用你管。
- 自己用服务器，要自己申请证书。Let's Encrypt 提供免费证书，AI 常会推荐它。证书有有效期，需要自动续期。
- 登录、支付、调用 [API](/words/api) 的页面，必须用 HTTPS。
- 微信小程序等平台要求服务端接口必须是 HTTPS，见[小程序](/words/mini-program)。

## AI提到它时，你该怎么接
```prompt
我的网站浏览器提示「不安全」或证书错误。网址是（填写）。请帮我判断原因：是证书没配、过期了、域名没对上，还是页面里混了 http 的资源，并给出修复步骤。
```

```prompt
我在自己的服务器上部署了网站，想启用 HTTPS 并让证书自动续期。系统是（填写）。请带我完成，每步说明目的。
```

## 容易踩的坑
- 域名刚解析完，证书还没签发好，访问会有一小段时间报证书错误。等一会儿，再确认。
- 页面是 https，里面却引用了 http 的图片或脚本，浏览器会拦截，这叫混合内容。在[控制台](/words/devtools)里能看到。
- 证书过期。自己管证书时尤其要注意设置自动续期。
- 本地开发用 http://localhost 是正常的，不必为它折腾证书。
