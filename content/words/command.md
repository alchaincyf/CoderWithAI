## 一句话
命令是你在[终端](/words/terminal)里输入的一行指令。通常先写动作，再写对象和选项，按回车执行。

## 打个比方
像给外卖小哥发的备注：「送到三号楼，放门口，别敲门」。动作、地点、附加要求，缺一个信息可能就送错。

不贴切的地方：外卖小哥会变通，命令不会。多一个空格、少一个横杠，结果可能完全不同。

## 你会在哪儿碰到它
命令长这样：

```bash
cd my-project
ls
npm install
```

几个最常见的：
- cd 进入某个文件夹，ls 列出里面有什么（Windows 的 PowerShell 里 ls 也能用）。
- mkdir 新建文件夹。
- npm install、npm run dev：装东西、启动项目，见 [npm](/words/npm)。
- 命令后面带的 --version、-y 这类叫「选项」，用来微调行为。

AI 给你命令时，通常会放在代码块里，右上角有复制按钮。

## AI提到它时，你该怎么接
你不确定一条命令是干什么的，先问再跑：

```prompt
你刚给的这条命令我看不懂：（粘贴命令）。请逐个部分解释它做什么，会不会删除或覆盖我的文件？确认安全后我再运行。
```

想让 AI 少给命令、多帮你执行：

```prompt
接下来需要运行命令的地方，请你直接在终端执行并告诉我结果。凡是会删除文件、覆盖内容或花钱的命令，先停下来问我。
```

## 容易踩的坑
- 照抄时漏掉空格，或把中文引号当成英文引号粘进去。命令里只认英文符号。
- 不看就运行带 rm 的命令。rm 是删除，通常不进回收站，删了就没了。
- 网上搜来的命令放到你的系统上不一定能跑：Mac 和 Windows 有区别。告诉 AI 你的系统。
- 一次粘贴多行，其中一行出错，后面的还是会继续跑。出错就停下，把报错发给 AI。
