## 一句话
计划模式是Claude Code里的一种工作状态：AI可以读文件、查资料、想方案，但在你批准计划之前，不会改你的代码。

## 打个比方
像装修前先出设计图。设计师量房、画图、报价，你点头签字后，才开始砸墙。

不贴切的地方：设计图只是图，计划模式里AI其实仍可能运行一些探索性命令来看情况，只是不改源码。

## 你会在哪儿碰到它
- 在Claude Code里按 `Shift+Tab` 循环切换模式，直到底部出现 `plan mode on`。
- 也可以单次在提示前加 `/plan`，或启动时用 `claude --permission-mode plan`。
- AI写完计划后会让你选择：批准并自动接受修改、批准并逐个确认每次修改、或「不，继续规划」让它改计划。
- 想先看或改计划，可按 `Ctrl+G` 在文本编辑器里打开。

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
（先切到计划模式）
我想给网站加一个「用户评论」功能。
请先读一遍现有代码，然后给我一份计划：
1. 你打算新增和修改哪些文件；
2. 数据库要加哪张表；
3. 有哪些风险（会不会影响现有页面）；
4. 分几步做，每一步我怎么验收。
有任何不确定的地方，先列出来问我。我批准后你再动手。
```

## 容易踩的坑
- 小改动也走计划：改个文字颜色不需要，浪费时间。适合改动大、涉及多个文件、你自己没把握的任务。
- 草率批准：计划里有你看不懂的地方就问，批准后它就开始改了。
- 批准前没有git存档：先[提交](/words/commit)一次，万一改坏能回退。
- 在批准界面按 `Shift+Tab` 会直接批准计划；想退出而不批准，先按 `Esc`。
