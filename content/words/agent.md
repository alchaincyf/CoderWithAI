## 一句话
Agent是能自己动手的AI。普通聊天AI只回答；Agent能在一个循环里：看情况、调用工具（读文件、运行命令、搜索网页）、看结果、再决定下一步，直到完成任务。

## 打个比方
聊天AI像电话顾问，只能告诉你怎么做。Agent像上门的师傅，工具箱带着，自己动手，做完告诉你。

不贴切的地方：师傅有经验，会自觉；Agent会误判、会乱动，所以才需要权限确认、[计划模式](/words/plan-mode)和[版本管理](/words/git)兜底。

## 你会在哪儿碰到它
- Claude Code、OpenAI Codex、Cursor的Agent模式，都属于这一类。
- 终端里看到它说「我先读一下这几个文件」「我来运行测试」，并弹出「是否允许执行此命令」的确认。
- 文档里的词：工具调用（tool use）、[MCP](/words/mcp)（接外部工具）、[Skill](/words/skill)（成套做法）、[子代理](/words/subagent)（分身）。

## AI提到它时，你该怎么接
```prompt 复制给 Claude Code
这个任务你自己完成，不要每一步都问我，但请遵守：
1. 开始前先用3句话说明你的做法；
2. 动手前确认我已经把当前代码提交到git；
3. 删除文件、联网下载、修改配置前先问我；
4. 做完自己运行检查，并把验证结果贴给我，而不是只说「完成了」。
```

## 容易踩的坑
- 给了太大的权限还不看：自动批准一切命令前，先确保有git存档和备份。
- 以为它说「完成了」就真完成了：要看它实际运行的证据。
- 目标含糊，它会自己发明目标，带来一堆你没要的改动。
- 把密钥、隐私文件放在它能读到的目录里：Agent读到的内容会发给模型服务商。
