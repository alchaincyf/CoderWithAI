## 一句话
脚本是把一连串要做的事写进一个文件里，需要时运行一次，电脑就按顺序全做完。

## 打个比方
像菜谱，也像清单。你本来要一步步手动做十件事，写成脚本后，只要说「开始」，它自己做完。

不贴切的地方：菜谱你看着做，出了错能随时调整，而脚本一旦运行，会一口气执行，不会停下来问你「这样对吗」。

## 你会在哪儿碰到它
- 让 AI 帮你批量重命名文件、定期备份、整理数据、一键打包，它常会写一个脚本。
- 文件后缀：.py（[Python](/words/python)）、.js、.sh（Mac 或 Linux 的 Shell 脚本）、.ps1（Windows PowerShell）。
- 运行方式依语言而定，例如 python3 clean.py 或 bash backup.sh，让 AI 告诉你。
- package.json 里的 scripts 也叫脚本：npm run build 就是运行里面写好的 build 那条。
- 有的脚本需要「可执行权限」才能直接运行，AI 会让你用一条命令给它加权限。

## AI提到它时，你该怎么接
```prompt
请写一个脚本帮我做：（描述）。要求：1. 先只预览不执行，我确认后再真正执行；2. 不要删除任何文件，需要清理的移到一个叫 _archive 的文件夹；3. 用最简单的语言实现，并告诉我怎么运行。
```

```prompt
我从网上拿到一个脚本（粘贴内容）。请逐行解释它做什么，有没有删文件、联网上传、读取密码之类的危险操作。确认安全前我不会运行。
```

## 容易踩的坑
- 运行陌生人给的脚本，有可能带恶意内容。先让 AI 解释，再决定。
- 脚本里的路径写死了你的用户名，换台电脑就失效。
- 带删除、覆盖功能的脚本没有先试跑。先在备份或测试文件夹里试。
- 脚本在错误的文件夹下运行，处理了不该处理的文件，见[路径](/words/path)。
