# CoderWithAI 内容写作规范（所有写作者必读）

## 这个站是谁、写给谁
coderwithai.top：AI编程时代的菜鸟教程。教**不会写代码的人**（产品经理、设计师、运营、学生、小老板、自媒体人、老师）用 Claude Code、Codex、Cursor、Trae 这类AI工具，把想法做成能上线的网站、工具和App。

读者的处境：AI替他写代码，但他得**听懂AI在说什么、知道下一步让AI做什么、卡住时知道怎么脱困**。我们不教语法，教「指挥AI所需的最少知识」和「真实世界里的坑」。

## 语气
- 像一个做过很多东西、很靠谱的朋友在旁边说话。不是培训机构，不是极客黑话，不卖焦虑。
- 短句。一段只讲一件事。先给结论，再给原因。
- 专业词第一次出现时立刻用一句人话解释，或链到词典：`[环境变量](/words/env-var)`。
- 不说「简单」「只需」「轻松」——对新手来说这些词是羞辱。
- 不写空话套话：「在当今时代」「众所周知」「赋能」「助力」「总而言之」一律不要。

## 准确性（职业信条）
- 命令、报错原文、菜单路径、价格、版本号：**必须查官方文档或真实报错样本核实**，不凭记忆。核实不了的不写，或写「以官方页面为准」并给链接。
- 不编造数据、案例、用户评价、「据统计」。
- 时效性强的信息（价格、额度、版本）写明「截至2026年11月」。
- 国内读者的真实处境要照顾到：网络（GitHub/npm 慢、部分服务需要海外网络）、付款（海外服务要外币卡）、备案、微信生态。说清楚，不回避，也不教违规手段。

## 排版
- 中文用「」引号；中英文之间、中文与数字之间**不加空格**（写「用Claude Code做」不写「用 Claude Code 做」）。
- 加粗稀缺使用，一篇最多三五处。不用 emoji。不用分隔线。
- 标题用 `##`（会自动进目录），小标题 `###`。
- 特殊语法：
  - 给AI的提示词用 ```prompt 代码块（会渲染成带「复制」按钮的提示词卡）。可以写 ```prompt 复制给 Claude Code 自定义标签。注意 prompt 后面的空格不能删，围栏信息串不适用「中英文之间不加空格」；命令、参数、文件名、语法示例（如 `python3 文件名.py`、`# 标题`）在正文里一律放进行内代码，里面的空格原样保留。**提示词要真能用**：具体、带上下文、告诉AI验收标准。
  - 报错原文用 ```error 代码块。
  - 终端命令用 ```bash 代码块（mac）或 ```powershell（Windows）。
  - 提示框：`> [!tip] 内容`、`> [!warn] 内容`、`> [!why] 内容`。
- 内链用站内绝对路径：`/words/<slug>`、`/fix/<slug>`、`/projects/<slug>`（栏目名叫「实战项目」，全站不用该栏目的旧称）、`/start/<slug>`。只链到清单里存在的 slug。

## 文件格式
每篇一个 `.md`，文件名 = `<slug>.md`，slug 用英文小写短横线。frontmatter 字段见各栏目要求，`updated: 2026-11-18`。
