## 你会做出什么

一个为手机竖屏设计的邀请页。打开先是封面（名字、日期、一张照片），上滑依次是：时间地点、日程、一句想对客人说的话、「怎么到达」按钮、「是否出席」回复入口。可以加一个倒计时，一段点一下才播放的背景音乐。

做完你拿到一个网址，在微信里发给亲友，点开就是这页。它不是微信里那种模板小程序，是你自己的网页，样式、文字、照片完全由你决定，也没有水印和会员费。

## 开始前准备

- 会用AI做出网页并在浏览器看到，见[第2关](/start/first-page)。
- 要让别人打开，需要上线，见[第3关](/start/go-live)。
- 素材：新人（或寿星）名字、日期时间、地点全名和详细地址、2到5张照片、想写的话、联系人电话（愿不愿公开由你定）。
- 照片先用手机或电脑自带工具压小。竖图宽度1200像素以内就够，每张尽量小于500KB，否则客人用手机流量打开会很慢。

> [!warn]请柬一旦公开，网址就是谁拿到都能看。地址、电话要想清楚再放。想要更保险，可以只放到区县级位置，详细地址另发给确认出席的人。

## 第1步：做出能看的第一版

```prompt 复制给AI
我是不会写代码的人，想做一个婚礼电子请柬（如果是生日，请把文案改成生日）。客人会在微信里点开链接，用手机竖屏看。

请先用5行以内说明计划，有拿不准的先问我，没有就直接做。

要求：
1. 只做一个index.html，样式和脚本都写在里面，不用框架，不依赖外部网络资源。图片放在images文件夹。
2. 手机竖屏优先：每个区块撑满一屏高度（用100svh），上滑切换；电脑上打开时，内容限制在420px宽、居中，两边留空白。
3. 区块：封面（大标题「我们结婚啦」、两人名字、日期、一张照片作背景）→ 时间地点 → 日程（3到5项）→ 一段话 → 联系我们。
4. 风格：暖白底，一个主色（酒红），标题用衬线字体（系统字体即可），留白多，克制，不要闪烁和粒子特效。
5. 内容用占位文字，每处占位前加「【待替换】」。照片用纯色占位块，并告诉我应放哪个文件名。
6. 区块进入屏幕时淡入一次，动画不超过0.6秒；如果系统设置了「减少动态效果」，则不做动画。

验收：浏览器手机模式（375×667和390×844两种尺寸）下，每一屏的文字都完整可见，没有被截断；没有控制台报错。
做完请自己打开检查，告诉我哪些你验证了，哪些需要我眼看。
```

你会看到：一个可以上下滑动的竖屏页面。如果每一屏的文字在小屏手机上被切掉，对AI说「375×667下第3屏文字被截断，请改成内容超出时可在该屏内滚动」。

## 第2步：换真内容和照片

把照片放进`images`文件夹，再发：

```prompt 复制给AI
请把请柬里所有「【待替换】」换成下面的真实信息，并接入images文件夹里的照片。
照片要求：自动适配屏幕，不变形（用cover裁切），裁切时尽量保留人脸，如做不到请告诉我哪张图需要我重新构图。
不要编造我没提供的信息，没有的就删掉那一块并告诉我。

名字：
日期时间（含星期）：
地点名称 +详细地址：
日程：
想对客人说的话：
联系人和电话：
照片文件名和用途：
```

## 第3步：加上「怎么到达」和倒计时

地图不要让AI做内嵌地图，那要申请密钥，还可能在微信里加载失败。更稳的做法是一个按钮，点一下复制地址，或跳转到手机地图App的搜索。

```prompt 复制给AI
请给请柬加两个功能：
1. 「怎么到达」区块：显示完整地址，两个按钮——「复制地址」（点击后按钮文字变成「已复制」2秒）；「打开地图搜索」（链接到高德地图网页版的地点搜索，搜索词为地点全名；请先告诉我你用的链接格式，并说明它在微信里能否打开）。不要引入任何需要申请Key的地图SDK。
2. 倒计时：显示「距离婚礼还有N天」，到当天显示「就是今天」，过了之后显示「谢谢你们的到来」。日期按北京时间计算，日期写在文件顶部一个变量里，方便我改。
做完用不同日期（未来、当天、过去）各测试一次，把结果告诉我。
```

## 第4步：回复入口（先用最稳的办法）

收集「来不来」，最稳的第一版不需要后台：做成一个按钮，点击后复制一段预写好的文字，或直接跳到你的微信。

```prompt 复制给AI
请在请柬最后加「是否出席」区块，不使用任何服务器和数据库：
1. 客人填写姓名、人数、是否出席（单选）。
2. 点「生成回复」后，页面把这些信息拼成一句话，如「我是张三，3人，会出席」，并提供「复制」按钮，旁边提示「复制后发给XXX微信」。
3. 不要保存和上传任何客人信息。
做完测试：不填姓名时给出友好提示，不能生成空回复。
```

想让回复自动汇总到你的表格，要用到数据库，参考[第4关](/start/save-data)和[记账本配方](/recipes/ledger-app)里的做法，或者就让客人直接微信回你，对一场婚礼来说往往更靠谱。

## 第5步：上线并在微信里实测

按[第3关](/start/go-live)推送到GitHub并部署到Vercel。然后用下面这条检查：

```prompt 复制给AI
请对线上网址做上线检查：图片是否都能加载（有没有大小写写错的文件名）、文件是否过大（列出超过500KB的图片）、手机竖屏是否正常、有没有控制台报错。最后给我一个「需要我处理」的清单。
```

最后一步AI做不了：把网址发到一个微信聊天里，用手机在微信里点开。很多读者是在这里发现问题的，比如图片太大加载转圈、音乐不响、字体变化。

> [!why]背景音乐为什么不会自动响：手机浏览器普遍禁止网页自动播放有声音的内容，必须用户点一下才行。所以做成「点右上角音符开始播放」，别指望自动。

## 怎么验收

- 微信里点开链接，3秒内看到封面（用移动数据测）。
- 每一屏在小屏手机和大屏手机上文字都完整。
- 时间、地点、日期，逐字对一遍，这是请柬唯一不能错的内容。
- 复制地址、地图跳转、倒计时、回复生成都点过。
- 发给两位家人，请他们不用你解释就能找到地点。

## 可以继续加的功能

- 相册区：「在日程后加一个照片墙，点击可放大，图片懒加载。」
- 背景音乐：「右上角加音符按钮，点击播放/暂停，音频文件放audio文件夹，不要自动播放。」
- 分享卡片：想让链接在微信里显示标题和缩略图，要在页面里写好og标签，但微信对自定义分享卡片的支持需要公众号和域名等条件，效果以实测为准。
- 红包/礼金二维码区块：「加一个区块展示我自己的收款二维码图片，旁边写一句话，默认折叠。」
- 自己的域名：国内访问更稳，见[domain](/words/domain)和[icp-filing](/words/icp-filing)。

## 常见坑

- `vercel.app`在部分国内网络下打不开，亲友里正好有人打不开就很尴尬。提前找不同网络的人试，对策见[vercel-blocked-in-china](/fix/vercel-blocked-in-china)。
- 大图没压缩，亲友在酒店用流量打不开。
- 日期时区算错，倒计时差一天。
- 地址写成简称，导航搜不到。用地图App里能搜到的全名。
- 发出去之后又改了日期，旧链接是同一个，但有人看的是微信里的缓存，改动要主动再通知一遍。
