## 你会做出什么

一个单文件的网页看板。打开它，选一个你的CSV或Excel文件（或拖进去），页面立刻变出：

- 顶部几张指标卡（总销售额、订单数、平均客单价……由你的数据决定）；
- 两到三张图：趋势折线图、分类占比或排名条形图；
- 一个可以搜索、排序、按条件筛选的明细表，筛选后上面的指标和图表跟着变；
- 一个「导出当前筛选结果」按钮。

数据在浏览器里本地处理，不会上传到任何服务器。所以你可以放心拿真实的业务数据试，也可以把这个文件直接发给同事，对方用自己的数据文件就能打开看。

## 开始前准备

- 会用AI做网页，见[第2关](/start/first-page)。
- 准备**一份真实的数据文件**，几百到几万行都行。第一份就用你自己真正在乎的数据，比如销售明细、投放数据、学生成绩。
- 用大白话写下你想回答的3个问题。例如：「哪个月卖得最好」「哪个渠道的转化率最高」「退款主要集中在哪些商品」。看板是为了回答问题，不是为了图多。
- 想一想数据是否涉及隐私或商业机密。本方案的数据不出你的电脑，但你把样例发给AI时要先脱敏（删掉姓名、手机号等）。

> [!tip]先给AI看数据的结构，不要给全量数据。复制表头加前10行就够了，敏感列替换成假数据。

## 第1步：让AI先读懂你的数据

```prompt 复制给AI
我是不会写代码的人，想把一份数据做成网页看板。先不要写代码。

我的数据文件是data.csv（放在项目文件夹里）。请：
1. 用Python或其他方式读取它（只读，不修改），告诉我：有多少行、多少列；每列的名字、你判断的类型（数字、日期、分类、文本）、缺失值数量、前5个不同的取值。
2. 指出数据里的问题：重复行、日期格式不统一、数字里混了符号（如「¥」「,」）、明显异常值。
3. 我最想回答这三个问题：（写下你的3个问题）。请告诉我：哪些问题这份数据能回答？哪些不能？需要哪几列？
4. 给出看板设计建议：该放哪几张指标卡、哪几张图（图类型和原因）、可筛选的字段。每张图说明它回答我哪个问题。
等我确认设计后再写代码。
```

你会看到：一份数据体检和一个设计方案。这一步最容易被跳过，也最重要：数据有问题，图表只会把错误画得更好看。

## 第2步：做出第一版看板

确认设计后发：

```prompt 复制给AI
请按我们确认的设计，做一个数据看板网页。

要求：
1. 单个index.html。需要的库：Chart.js（画图）、PapaParse（读CSV）、SheetJS（读xlsx）。请先去各自官方文档确认当前的稳定版本号，把库文件下载到项目的vendor文件夹本地引用，不依赖外部CDN（国内访问不稳），写明版本号和来源。
2. 页面顶部有「选择文件」按钮和拖放区域，支持 .csv和 .xlsx。所有处理在浏览器本地完成，不发送任何网络请求。
3. 读取后自动识别列类型。我的数据列是：（粘贴表头）。日期列是（列名），金额列是（列名）。
4. 版面：顶部指标卡 → 图表区（响应式：电脑两列，手机一列）→ 筛选条（日期范围、分类下拉、搜索框）→ 明细表（可点击表头排序，分页每页50行）。
5. 筛选联动：任何筛选变化，指标卡、图表、明细表同步更新。
6. 数据清洗放在单独的函数里，并在页面角落显示「已忽略N行无效数据」，不能悄悄丢数据。
7. 图表规范：坐标轴有标签；颜色不超过6种，并且色盲友好；只有一个主色用于强调；图表标题写成结论式的话（如「3月销售额最高」要由数据算出来，不是写死）。
8. 视觉：浅色，克制，数字右对齐，千分位分隔，金额保留两位小数。
9. 先用我的data.csv作默认示例加载（页面上标明「示例数据」）。

验收：我提供的3个问题都能在页面上找到答案；筛选后总额与明细表求和一致（请你自己用代码验证）；上传一个只有表头的空文件、一个列名不对的文件，页面给出友好提示而不是崩溃。自己运行并如实报告。
```

你会看到：一个能交互的看板。试着筛选，看指标卡的数字变不变。

如果不对：

- 空白页：打开F12看控制台，常见是库文件路径写错，见[blank-page](/fix/blank-page)。
- 中文乱码：CSV编码问题（Excel导出的CSV常用GBK）。对AI说「文件读出来中文是乱码，请支持自动识别UTF-8和GBK编码」。
- 数字和你Excel里算的对不上：别先怀疑Excel，让AI逐步说明它怎么算的，往往是遗漏了空值或把文本当数字。

## 第3步：核对数字，这是看板的生命线

```prompt 复制给AI
请你独立核对看板上每一个数字：用另一种方式（例如Python直接读取原文件计算）算出所有指标卡的值、每张图的前三个数据点，与网页上显示的对比，输出对照表。再选2种筛选条件，核对筛选后的数字。有任何不一致请指出原因并修复。
```

你会看到：一张「网页值vs独立计算值」的对照表。有任何差异都必须解释清楚才能继续。

## 第4步：让它真的好用

用一周，记下你用它时觉得烦的地方，再一起交给AI：

```prompt 复制给AI
我用了几天，有这些不顺手：
1. （例如：每次都要重新选文件，想记住上次的文件）
2. （例如：图表上看不到具体数值，鼠标移上去要显示）
3. （例如：想把当前看板导出成一张图发给老板）
请逐条给出方案并说明代价（比如浏览器出于安全不能记住本地文件路径），我确认后再做。
```

## 第5步（可选）：上线分享

文件是纯静态的，可以按[第3关](/start/go-live)部署到Vercel，别人打开后选自己的文件使用。**不要把真实数据文件放进公开仓库**。示例数据请换成脱敏后的假数据。

## 怎么验收

- 三个问题，每个都能在页面上30秒内找到答案。
- 页面上的每个关键数字，与独立计算结果一致。
- 换一份同结构的新数据，直接加载就能出图，不用改代码。
- 数据不出浏览器：打开F12的Network面板，加载文件时没有任何上传请求。
- 手机宽度下可以看，图表不溢出。

## 可以继续加的功能

- 同比环比：「指标卡增加与上个周期对比的涨跌，红涨绿跌或蓝橙，请照顾色盲。」
- 多文件对比：「允许加载两个文件并排对比。」
- 自动洞察：「在顶部用一句话列出3个最显著的变化，每句话后面标注依据的数字，不允许写数据里没有的结论。」
- 定时更新：看板要自动读取新数据，就需要把数据放到服务端，难度上升到[第4关](/start/save-data)的范围。
- 导出报告：「把当前看板导出成一页PDF。」

## 常见坑

- 数据没清洗就画图：日期格式混乱、金额带符号、重复行，图表照样画出来，但是错的。
- 图表太多。每张图都必须对应一个你要回答的问题，回答不了就删。
- 悄悄丢弃无效行，用户毫不知情。
- 把含客户信息的原始表放进公开仓库。
- 大文件卡顿：几十万行以上的文件在浏览器里会很慢，让AI先做抽样或汇总，或者换成Python预处理。
