## 你会做出什么

一个只有一页的个人网站：最上面是你的名字、一句话介绍和头像；往下依次是「我能做什么」「作品」「经历」「联系我」。手机上单列排版，电脑上居中留白，字大、配色克制，不花哨。

做完之后你手里有一个类似 `你的项目名.vercel.app` 的网址。简历里、微信签名里、名片二维码里放这一个链接就够了。内容改了，一条提示词加一次推送，线上就跟着更新。

整个页面是一个 `index.html` 加几张图片，没有数据库，没有后台，所以不会坏，也不花钱。

## 开始前准备

- 一个装好的AI编程工具（Claude Code、Codex、TRAE都行），见 [第1关](/start/setup)。
- 会建项目文件夹、会让AI做出网页并在浏览器打开，见 [第2关](/start/first-page)。
- 一个GitHub账号和一个Vercel账号，上线的方法见 [第3关](/start/go-live)。
- 你自己的素材，写在一个文本里就行：姓名、一句话介绍、3到6个作品或经历（每个一两句话）、联系方式。头像或作品图可选。

> [!tip] 素材不全也能开工。第一版让AI用占位文字，你再逐段替换成真的。但上线前一定要把占位文字全部换掉。

联系方式要想一想放哪些。公开网页谁都能看到，手机号和住址最好别放，留邮箱或微信号二维码就够用。

## 第1步：先在本地做出第一版

新建一个文件夹，比如 `my-page`，用AI工具打开它，然后发这条：

```prompt 复制给AI
我是完全不会写代码的人，想做一个一页式个人主页，用来放简历和作品，发给招聘方和客户看。

请先用不超过5行说明你的计划。有拿不准的地方先问我，没有就直接做。

要求：
1. 只生成一个 index.html，样式写在同一个文件里，不用任何框架，不依赖外部网络资源（字体用系统字体）。
2. 手机优先：手机上单列，电脑上内容最大宽度 720px 居中。
3. 区块顺序：顶部（姓名、一句话介绍）→ 我能做什么（3项）→ 作品（3个卡片）→ 经历（时间线）→ 联系我。
4. 风格：浅色背景，一个主色（深蓝），正文 17px 以上，行距宽松，留白多，不要渐变、不要动画、不要emoji。
5. 内容先用占位文字，但占位文字要像真的，并在每处占位前加「【待替换】」，方便我搜索。
6. 页面 <title> 和描述写好，方便被搜索和分享。

验收标准：用浏览器打开 index.html 能看到完整页面；把窗口缩到手机宽度（375px）没有横向滚动条；没有控制台报错。
做完请你自己打开检查，告诉我哪些项你亲自验证了，哪些需要我用眼睛确认。
```

你会看到：文件夹里多了 `index.html`，AI会告诉你双击就能打开。用浏览器打开，应该是一页完整的、带占位文字的主页。

如果不对：

- 页面是空白的：见 [blank-page](/fix/blank-page)。
- 样式乱了或没生效：对AI说「样式没生效，请检查index.html的style标签是否闭合，并打开浏览器自查」。
- 太花哨或太素：别说「好看一点」，说具体的，比如「标题再大一号，作品卡片加一条浅灰边框」。

## 第2步：换成你的真内容

把你的素材整段粘贴进去，让AI替换：

```prompt 复制给AI
下面是我的真实资料，请替换掉 index.html 里所有「【待替换】」的内容。
只改文字，不动样式和结构。资料里没有的信息不要编造，没有就删掉那一块，并告诉我删了哪块。

姓名：
一句话介绍：
我能做什么：
作品1（名称、一两句话、链接，没有链接就留空）：
作品2：
作品3：
经历（时间、地点、做了什么）：
联系方式（邮箱 / 微信号）：

改完后搜索一遍「待替换」，确认一处都没剩，再告诉我结果。
```

你会看到：页面里全是你自己的内容。AI偶尔会「润色」出你没做过的成果，所以自己通读一遍，每一句都必须是真的。

## 第3步：手机上过一遍，再改三轮

用手机浏览器打开本地页面比较麻烦，可以先用电脑浏览器的手机模式（Chrome：按F12，点左上角的手机图标）。看三件事：字够不够大、按钮好不好点、邮箱能不能点一下就弹出写信窗口。

```prompt 复制给AI
请按手机用户的视角检查并改进 index.html：
1. 邮箱做成点击即可写信的链接，微信号旁加一个「复制」按钮。
2. 作品卡片整张都可点击（有链接的话），点击区域至少 44px 高。
3. 给页面加一个「回到顶部」链接。
4. 页面加上 Open Graph 标签（og:title、og:description），图片先不加。
先列出你要改的点，改完自己检查，不要动我已经填好的文字。
```

## 第4步：上线，拿到网址

流程和第3关一样：把文件夹推送到GitHub，在Vercel里导入这个仓库，点部署。如果你已经做过，让AI带你走一遍：

```prompt 复制给AI
请带我把这个项目上线。我有 GitHub 和 Vercel 账号，但不熟。
1. 先检查项目里有没有不该公开的内容（密码、手机号、私人地址），有就告诉我。
2. 初始化 Git、提交，并告诉我怎样在 GitHub 上创建仓库并推送。需要我在网页上点的步骤，请一步一步列出来。
3. 告诉我在 Vercel 导入仓库时每一项该怎么选（这是纯静态页面，不需要构建命令）。
每一步都等我确认完成再进入下一步。
```

你会看到：Vercel的部署页状态变成Ready，给出一个 `.vercel.app` 网址。用手机关掉Wi-Fi、走流量打开它，能看到页面，才算成功。

如果不对：部署失败看 [vercel-build-failed](/fix/vercel-build-failed)，打开是404看 [vercel-404](/fix/vercel-404)，推送被拒绝看 [git-push-rejected](/fix/git-push-rejected)。在国内，`vercel.app` 域名有时访问不稳，见 [vercel-blocked-in-china](/fix/vercel-blocked-in-china)。

## 怎么验收

- 手机走流量打开你的网址，页面完整，没有「待替换」字样。
- 页面里每一条经历和成果，你都能当面讲清楚。
- 点邮箱能写信，点作品链接能跳转，没有死链。
- 把网址发给一个朋友，让他不看说明直接找到你的联系方式，用时不超过10秒。
- 改一个字，推送，刷新线上网址能看到变化。这一步证明你掌握了「改了再发」。

## 可以继续加的功能

- 深色模式：「让页面跟随系统切换深色模式，深色下文字对比度要够，所有颜色用CSS变量管理。」
- 中英双语：「加一个语言切换按钮，中文和英文内容都放在页面里，切换时不刷新，默认语言按浏览器语言决定。」
- 自己的域名：先买域名，再让AI带你在Vercel里绑定，见 [domain](/words/domain)。
- 分享卡片：「做一张1200×630的分享封面图，写进og:image，说明图片应放在哪个文件夹。」
- 访问统计：「接入一个不使用Cookie的访问统计服务，先给我对比两个选项再动手。」

## 常见坑

- 把手机号、身份证相关信息写进公开页面。上线前让AI搜一遍。
- 图片直接用手机原图，几MB一张，页面打不开。让AI把图片压缩到每张300KB以内。
- 推送后立刻去看，部署还没完成，看到的是旧版。等Vercel状态变成Ready。
- 只改了本地文件，没推送。改完要确认线上网址真的变了，见 [deploy](/words/deploy)。
- 想让别人搜到你，要给它时间。新站被搜索引擎收录通常需要几天到几周，不是上线当天的事。
