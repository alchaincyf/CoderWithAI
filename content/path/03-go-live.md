## 这一关你要做成什么

让一个不在你电脑旁边的人，也能打开你的网页。

做到这条就算过：用手机，关掉WiFi，用4G打开你拿到的网址，能看到第2关做的个人小站。

先说一个现实：这一关的默认路径是GitHub加Vercel，它们对海外访问友好、对新手最顺，但在中国大陆的访问可能不稳定。这一关会把这件事讲透，并给出国内的备选思路，你可以先走默认路径跑通流程，再决定要不要换。

## 先懂一件事：网页上线，就是把文件放到一台一直开着的电脑上

你电脑上的 `index.html` 只有你能看到。上线，是把它放到一台不关机、有公网地址的电脑（[服务器](/words/server)）上，别人输入网址就能取到。这个动作叫[部署](/words/deploy)。

我们走的路线是三站接力：

1. 你的电脑：存放项目，用Git存档（第2关做过了）。
2. [GitHub](/words/github)：网上的项目仓库，把你的存档同步上去。
3. [Vercel](/words/vercel)：从GitHub取走你的文件，发布成网址。之后你每次往GitHub上传新版本，它自动重新发布。

像寄快递：你打包（Git存档），送到中转站（GitHub），由快递公司（Vercel）派送到收件人手里。

我们的小站是纯静态网页（见[静态站点](/words/static-site)），没有后端，部署最不容易出错，非常适合第一次。

## 动手

### 第1步：注册GitHub账号

访问github.com，注册账号，按页面提示验证邮箱。用户名会出现在你的仓库网址里，起个你愿意公开的名字。

你会看到：注册完成后进入你的GitHub主页。

如果看到别的：页面打不开或特别慢，见[GitHub连接超时](/fix/github-connect-timeout)。验证邮件迟迟不来，先检查垃圾邮件箱。

### 第2步：创建一个空仓库

登录后，点页面右上角的加号图标，选择「New repository」。官方文档的步骤是：

1. 在「Repository name」里填一个短名字，比如 `my-site`。
2. 选择仓库可见性：公开（Public）任何人可见，私有（Private）只有你可见。个人小站里没有秘密，选哪个都能部署到Vercel；有任何不想公开的内容就选私有。
3. 这次不要勾选「Add README」之类的初始化选项，我们要的是空仓库，因为本地已经有内容了。
4. 点「Create repository」。

你会看到：一个几乎空白的页面，上面给出了几行建议命令。这个页面保留着，下一步要用到仓库网址。

如果看到别的：仓库名已被占用，换一个名字。

### 第3步：让AI帮你把项目推上去

推送（[push](/words/push)）就是把本地存档上传到GitHub。这一步需要GitHub确认「你就是你」。注意：GitHub早就不支持用账号密码推送了，见[GitHub密码验证失败](/fix/github-password-auth)。最省事的做法是让AI帮你装GitHub官方命令行工具并走浏览器授权，你把话说清楚就行。

回到你的AI工具（项目文件夹 `my-site`），粘贴，把网址换成你仓库页面上的那个：

```prompt
我在 GitHub 上建好了一个空仓库，网址是（粘贴你的仓库网址）。请帮我把当前项目上传上去：
1. 先运行 git status 和 git log，告诉我当前是否已有存档，没有就先帮我存档。
2. 检查项目里有没有不该上传的东西（密码、密钥、.env 文件、个人隐私文件）。有的话先告诉我，不要上传。
3. 把仓库地址设为远程地址，主分支叫 main，然后推送。
4. 如果需要登录 GitHub，请告诉我最推荐的登录方式（比如 GitHub 官方命令行工具 gh 的浏览器授权），并一步步带我完成。涉及要我在浏览器里点的地方，告诉我该点什么。
5. 不要使用 --force，不要在命令里写我的密码。
每一步做完告诉我结果，卡住就停下来问我。
```

你会看到：AI先汇报检查结果，然后推送。如果需要登录，它可能让你在浏览器里输入一个验证码或点击授权按钮，按它说的操作。成功后，刷新GitHub上的仓库页面，你的 `index.html`、`AGENTS.md` 等文件都出现了。

如果看到别的：

- 提示被拒绝或不同步，见[推送被拒绝](/fix/git-push-rejected)。
- 连接超时，见[GitHub连接超时](/fix/github-connect-timeout)。
- 如果上传了不该上传的密钥，立刻看[密钥泄露了怎么办](/fix/secret-leaked)。

### 第4步：在Vercel导入仓库并部署

访问vercel.com，注册账号。注册时它提供用GitHub账号登录的选项，用这个最方便，因为后面需要连接GitHub。

Vercel官方文档给的路径是：打开New Project页面（vercel.com/new），连接你的GitHub账号，选中仓库，点「Deploy」。

你会看到：授权GitHub时，GitHub会问你允许Vercel访问哪些仓库，建议只选你要部署的这个。回到Vercel后，你的 `my-site` 仓库出现在列表里，旁边有类似「Import」的按钮。点进去，会出现项目设置页，我们的静态小站一般不用改任何设置，保持默认，点页面上的「Deploy」。

等待片刻，页面显示部署成功，并给出一个以 `.vercel.app` 结尾的网址，还能点开预览。

如果看到别的：

- 部署失败，页面有红色报错，把完整日志发给AI，或看[Vercel构建失败](/fix/vercel-build-failed)。
- 网址打开是404，见[Vercel 404](/fix/vercel-404)，常见原因是 `index.html` 没放在仓库的根目录。

### 第5步：手机验收

把网址发到你的手机上，关掉WiFi，用4G或5G打开。

你会看到：你的个人小站，和电脑上一样。

如果看到别的：打不开或特别慢。先别慌，这很可能不是你的问题，下一节专门讲。

### 第6步：改了再发

这是体验到「上线不是终点」的一步。回到AI，让它改一个小地方：

```prompt
请把页面标题下面的第一句话改成（你想要的新文案）。改完后帮我存档，提交说明写「更新首页文案」，然后推送到 GitHub。推送后告诉我 Vercel 会自动做什么。
```

你会看到：几十秒到几分钟后，刷新你的网址，文案变了。在Vercel的项目页，你能看到新增了一次部署记录。官方文档说明，每次推送到连接的分支，都会自动触发一次新部署。

如果看到别的：网址没变，先强制刷新浏览器（Mac按Command+Shift+R，Windows按Ctrl+F5），再去Vercel看最新那次部署是否失败。

## 国内访问的现实，以及你的选择

**Vercel官方的说法是：它在中国大陆没有服务器和CDN节点，访问要绕远路，`vercel.app` 这类子域名也可能被限制；是否可访问因域名、运营商和时间而异，官方也无法保证大陆的可用性和性能。**这条在[vercel.app在国内打不开](/fix/vercel-blocked-in-china)里有完整说明。

所以，如果你的手机4G打不开网址，不代表你做错了。你有这几种选择：

### 选择一：先过关，不管国内

如果你的读者主要在海外，或者你只是想学会流程，默认路径够用。让不在大陆的朋友打开试试，也算验证了部署成功。

### 选择二：绑自己的域名

买一个[域名](/words/domain)，绑到Vercel项目上。官方文档的路径是：进入项目的Settings，选Domains，点类似「Add Existing」的按钮，输入域名，然后按页面提示去域名服务商那里加一条解析记录：根域名（如example.com）用A记录，子域名（如docs.example.com）用CNAME记录。页面会显示具体要填的值，照抄，不要用别的项目的值。

自定义域名被限制的可能性比 `vercel.app` 低，但Vercel也说没有哪个域名是免疫的。所以这是缓解，不是保证。想弄清解析是什么，看[DNS](/words/dns)。绑完不生效，见[域名不生效](/fix/domain-not-working)。

买域名的价格各家不同，请以注册商页面为准。

### 选择三：放到国内平台，面向大陆用户

这是面向大陆用户最稳的路线，代价是要做[ICP备案](/words/icp-filing)。

我没能在官方页面核实到各家国内静态托管产品的当前名称、价格和备案细则，所以这里只讲原则，具体产品请你去官网确认：

- 腾讯云、阿里云等国内云服务商，都有放静态网页的产品（常叫静态网站托管、对象存储加CDN、边缘站点之类）。腾讯云的EdgeOne Pages，我查到资料称它支持从GitHub导入并随提交自动构建，但它的价格政策、国内节点是否需要备案，我没有在官方页面核实，请以官网和客服为准。
- 一般原则（见词典）：使用大陆节点并绑定域名对公众提供服务，需要先完成ICP备案，通过云服务商的备案系统提交，要等几周，期间域名通常不能解析到网站。个人备案一般不能做经营性网站。以工信部和服务商最新要求为准。
- 如果你选的是海外节点，一般不需要这个备案，但国内访问速度可能不好。
- 流程上你照样可以用GitHub存代码，只是把「Vercel接管发布」换成这家平台的发布方式。你可以直接问AI：

```prompt
我的静态网页项目在 GitHub 上，仓库是（网址）。我想让中国大陆用户稳定访问。请帮我对比腾讯云和阿里云各自提供的静态网页托管方案：名称、怎么从 GitHub 部署、价格构成、是否需要备案、备案流程大概多久。请只依据它们的官方文档回答，每条结论附上官方文档链接，查不到的明确说查不到，不要凭印象。最后给我一个推荐，说明理由，先不要动我的项目。
```

> [!warn] 网上有教你用各种「加速」「翻墙」手段让Vercel在国内直连的方法，既不稳定，也可能违规，本站不提供。

### 关于免费档的一个提醒

Vercel的服务条款（vercel.com/legal/terms）写明，Hobby免费档只能用于个人或非商业用途。你的个人小站没问题；如果以后做出要收钱的产品，需要升级付费档，到第7关再细讲。官方定价页显示Hobby是每月0美元（2026年11月），并有每月用量上限，个人小站远用不到。

## 验收：怎么知道真的成了

- GitHub仓库页面里能看到你的文件。
- Vercel项目页显示部署成功，有一个网址。
- 手机关掉WiFi后能打开网址（或者：在国内打不开时，已让海外朋友验证过，并明确了自己的下一步选择）。
- 你改一次文案、推送一次，线上网址确实更新了。

## 最常卡在这几个地方

1. GitHub连不上或很慢：见[GitHub连接超时](/fix/github-connect-timeout)。
2. 推送要求输入密码又失败：见[GitHub密码验证失败](/fix/github-password-auth)。
3. 推送被拒绝：见[推送被拒绝](/fix/git-push-rejected)。
4. 部署后404或构建失败：见[Vercel 404](/fix/vercel-404)和[Vercel构建失败](/fix/vercel-build-failed)。
5. 国内手机打不开：见[vercel.app在国内打不开](/fix/vercel-blocked-in-china)。
