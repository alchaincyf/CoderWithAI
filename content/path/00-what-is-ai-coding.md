## 这一关你要做成什么

不动手，只做一个决定：你走哪条线。

读完以后，你应该能填完这句话：「我走（国内线／国际线／先用网页工具试水），用（具体工具名），这个月预算（金额）。」填得出来就算过关。

## 先懂一件事：你是产品经理，也是验收人，AI是工程师

AI编程不是「AI替你学会了写代码」，而是分工变了。

你管三件事：想清楚要什么，把它说清楚，检查做出来的对不对。AI管一件事：把你说清楚的东西写成代码、跑起来、报告结果。

像请装修师傅。你不用会砌墙，但你得说清「客厅要多大、颜色偏暖、插座放哪」，师傅干完你要验房：开关灵不灵，墙平不平。你说「随便弄弄」，得到的就是随便弄弄。

所以这个站教的不是语法，而是三种能力：

1. 说清需求。第2关专门练。
2. 听懂AI在说什么。遇到陌生词查[词典](/words/vibe-coding)，别硬记。
3. 验收和止损。看得出对不对，错了知道怎么退回去。

AI会做错，会一本正经地编造不存在的东西（见[幻觉](/words/hallucination)）。它不是不可靠，而是需要被检查。检查，是你的活。

### 它能做到什么，做不到什么

截至2026年11月，不会写代码的人借助AI工具，做出下面这些是现实的：个人主页、活动邀请页、小工具、记账或打卡类小应用、带登录和数据库的小产品。本站后面的闯关路线，就是沿着这条线走到「能收钱」。

做不到或不该指望的：

- 「一句话生成一个成熟产品」。第一版能出来，但要打磨、改十几轮才能用。
- 不检查就上线涉及钱、隐私、医疗的东西。
- 完全不理解就一路点「同意」。后面会教你至少看懂它在改什么。

## 三类工具，你在哪一类开始

2026年的工具已经互相渗透（编辑器长出了命令行，命令行长出了桌面App），但对新手来说，仍可以按「你怎么跟它说话」分三类。

### 第一类：网页一句话生成

打开网页，写一句话，等它生成一个能点的网站或应用。不用装任何东西。例子：国内的扣子编程、秒哒；国外的Lovable、Bolt、v0、Replit Agent。

适合：只想先看看「AI做东西」长什么样；急着要一个临时页面；对代码一点兴趣都没有，只要结果。

限制：改到后面容易「牵一发动全身」；你对项目的掌控少；额度用完就得付费。它是很好的第一次体验，但不是本站闯关路线的主角。

### 第二类：AI编辑器

像一个带AI对话框的编辑软件，你能看到文件列表和代码，AI在旁边改。例子：TRAE、Cursor、Qoder、CodeBuddy。适合想「看着东西长出来」的人，界面是图形化的，不怕终端。

### 第三类：命令行Agent

在[终端](/words/terminal)里跟AI对话，它自己读你的文件夹、改文件、跑命令、修错。例子：Claude Code、Codex、Kimi Code。上限最高，也最接近现在专业人士的工作方式；代价是要和一个黑窗口打交道。本站第1关会一步步带你过这一关。

## 国内线还是国际线：用三个问题判断

问自己：

1. 我在中国大陆，并且没有稳定、合规的海外网络和能付外币的卡吗？
2. 我愿意每个月花约20美元（按当期汇率折算人民币）吗？
3. 我想要最强的工具，还是先零成本上手？

### 国内线：没有海外网络和外币卡也能走

核心工具是TRAE国内版（trae.cn）。截至2026年11月，官网定价页显示：免费版0元，每月500积分，所有功能可用，支持同时执行2个云端任务。付费档首月有优惠价，下单以页面为准。

积分够做多少事，我没有办法给你一个数。官方没有给出「一个项目约耗多少积分」，所以本站不替你估。建议第一个月先用免费档跑完第0到3关，看看自己消耗多少，再决定要不要付费。

想用命令行的，可以选Kimi Code。它给出了大陆专用接入地址，用Kimi会员账号登录，具体价格和购买方式请看官网（kimi.com/code）。

其他国内选择：CodeBuddy（腾讯，体验版每月500积分）、Qoder国内版（qoder.cn）、通义灵码（个人使用免费）。它们的价格和活动常变，下单前以官网为准。

国内线的优点：不碰网络合规问题，人民币付款，能直接上手。缺点：工具和模型的选择少一些，后续「上线」一关，国内访问和国外服务之间要多做取舍（第3关细说）。

### 国际线：Claude Code或Codex，约20美元一个月起

- Claude Code：官方文档写明需要Pro、Max、Ultra、Team、Enterprise或Console账号，免费账号不含。Pro月付20美元，年付折合约17美元一个月（2026年11月）。
- Codex：用ChatGPT账号登录，Plus是20美元一个月（2026年11月）；官方还有Free和Go（8美元一个月）两档，额度较少，具体以官网为准。

必须如实告诉你一件事：**Anthropic官方支持的国家和地区名单里，不包含中国大陆。**名单之外一律不支持。这意味着在大陆直接使用Claude Code，不合规，也可能被封号。本站不教、也不推荐任何绕过限制的办法，包括代购账号和机场。Codex在大陆的可用性，我没有在官方页面核实到，请你自行确认。

所以国际线只适合：本人长期在官方支持的地区，或者你所在单位有合规的企业渠道。如果你在大陆，没有这些条件，请走国内线，没有任何丢人的地方。登录遇到地区提示，见[Claude Code登录失败、地区不支持](/fix/claude-code-region)。

### 一张表看清

| | 国内线 | 国际线 | 网页一句话生成 |
| - | - | - | - |
| 代表 | TRAE国内版、Kimi Code | Claude Code、Codex | 扣子编程、Lovable等 |
| 要海外网络 | 不要 | 要，且账号地区需受支持 | 国内产品不要，国外产品请自行确认 |
| 起步花费 | 0元（TRAE免费版每月500积分） | 约20美元一个月 | 看产品，免费额度很有限 |
| 适合 | 零基础大陆用户 | 在受支持地区、想要最强工具的人 | 只想先看一眼的人 |

网页一句话生成的价格，我只核实到几个：扣子编程个人免费版是0积分，实质要付费，进阶版49元一个月（首月39元），每月2000积分；Lovable免费档每天有少量额度，Pro是25美元一个月（均为2026年11月）。这类产品额度规则变化很快，付费前请以官网为准。

### 预算怎么定

第一个月：国内线0元；国际线约20美元。先别买高档位，Max、Pro+这种一百美元以上的档位是给每天重度使用的人准备的。

另外，上线（第3关）用的GitHub和Vercel有免费档，域名要另外花钱，价格各家不同，到时候再看，不急。

## 动手

这一关只有一个动作，选线：

### 第1步：回答三个问题

在纸上写下：我在哪、我能不能合规地用海外服务、我愿意每月花多少。

你会看到：答案基本会把你分到国内线或国际线。大多数大陆读者会落在国内线。

如果看到别的：既没有预算也不想装东西，先用一个网页工具玩半小时，回头再选。拿不准是否合规，选国内线。

### 第2步：写下你的选择

复制下面这句，填空：

```prompt
我走（国内线／国际线），用（TRAE国内版／Kimi Code／Claude Code／Codex），每月预算（金额）。我想做的第一个东西是（一句话）。
```

这句话不用发给任何人，写在备忘录里。第2关你会拿它当起点。

## 验收：怎么知道真的成了

- 我能说出自己走哪条线，以及为什么。
- 我知道自己的预算，不会因为一时冲动买了高档位。
- 我明白：我负责说清需求和验收，AI负责写代码。
- 我知道Claude Code在大陆不在官方支持范围内，不会去找绕过的办法。

## 最常卡在这几个地方

1. 纠结选哪个最强。第一个作品用不到最强，选你能稳定用上的那个。
2. 看到别人用Claude Code，想硬上。先看[地区不支持怎么办](/fix/claude-code-region)。
3. 用着用着额度没了。见[Claude用量限制](/fix/claude-usage-limit)。
4. 对话越来越长，AI开始糊涂。见[上下文满了](/fix/context-full)，第2关会教怎么预防。
