## 这一关你要做成什么

把你的作品装进手机：点桌面上一个图标，或者在微信里点开，就能用，不用再记网址。

三条路里选一条走完，不要三条一起做。第一次走，我建议先做PWA，因为它最省事、不花钱、不用审核，而且做完它，你会更清楚自己是否真的需要另外两条。

过关标准：你自己的手机上有这个作品的入口，从入口打开能正常使用。

## 先懂一件事

### 三条路，其实是三种「装进手机」的方式

网页本身就能在手机浏览器里打开。「做成App」的意思，是让它长得更像一个App：有桌面图标，打开时没有浏览器的地址栏，能被找到。三条路的区别在于，这件事由谁来批准。

- [PWA](/words/pwa)：你的网页，加一个说明书（manifest），用户自己把它加到桌面。没有人批准你，用户自己决定。
- [微信小程序](/words/mini-program)：住在微信里的轻应用。微信批准你，规矩由微信定。
- iOS App：装在iPhone上的原生应用，经过苹果审核，上[App Store](/words/app-store)。苹果批准你。

越往后，门槛越高，能力也越强，能碰到的用户和功能也越多。

### 对比表

下面的费用和规则，除特别注明外来自各家官方页面（2026年11月）。规则会变，动手前请再看一眼官方。

| | PWA | 微信小程序 | iOS App |
|---|---|---|---|
| 成本 | 0元，Vercel上线就带HTTPS | 以微信公众平台后台显示为准 | 加入Apple Developer Program，每年99美元（当地货币计价的地区以报名页为准） |
| 门槛 | 低：在现有网页上加配置 | 中：要重写成小程序的写法，不能照搬网页 | 高：要有Mac和[Xcode](/words/xcode)，代码要重写成原生 |
| 审核 | 没有 | 有，通过后要自己点发布才上线 | 有，被拒是常事，改了重交 |
| 用户怎么拿到 | 发网址，用户自己「添加到主屏幕」 | 扫码或搜索，不用下载 | App Store下载，或[TestFlight](/words/testflight)邀请内测 |
| 能收钱吗 | 用你自己接的支付，见第7关 | 个人主体做不了微信认证，也就接不了普通微信支付；企业或个体工商户主体才行 | 数字内容和服务要走苹果内购，官方页面写的佣金是30%，符合小企业计划的是15% |
| 国内要不要备案 | 用国内服务器和域名才要，见[备案](/words/icp-filing) | 请求你自己服务器的域名，要配成合法域名，需要HTTPS，通常需要备案 | 上架中国大陆区涉及App备案，以苹果和工信部最新要求为准 |
| 适合什么 | 工具、内容、需要快速试错的作品 | 用户本来就在微信里的生活服务、社群、轻工具 | 要推送、相机、传感器、小组件，或者想做长期的正式产品 |

有两处我必须说明哪里没有核实到官方原文：小程序个人主体能做什么、不能做什么，我没能打开微信官方的注册说明页，上表依据的是本站词典和第三方报道；App备案对App Store的具体执行细节，也没在苹果官方页面查到，只看到工信部2023年8月的通知和媒体对执行情况的报道。这两处请以官方当前页面为准。

### 选哪条：三个问题

1. 你的用户在哪里？大多在微信里（家长群、客户、同事），倾向小程序。在各种渠道，倾向PWA。
2. 你要用手机独有的能力吗？推送通知、相机深度使用、小组件，倾向iOS App。PWA在iPhone上也支持网页推送，但官方（Next.js文档）写明需要iOS 16.4以上，并且要先添加到主屏幕。
3. 你愿意等审核、花钱、学新东西吗？不愿意，PWA。

本关不展开Android原生应用。PWA在安卓的浏览器里同样能装，已经够用。

## 动手

### 第1步：选定一条，并决定「这次只做一件什么功能」

不要把整个作品搬过去。小程序和原生App都需要重写，先搬一个最小的功能，比如第4关那个「笔记」，或者一个不联网的小工具。

```prompt复制给Claude Code或TRAE
我已经做好了一个网页作品，现在想让它装进手机。请先阅读当前项目，然后帮我做决策分析，不要改任何文件：
1. 用三句话总结这个作品现在有哪些功能。
2. 我的用户主要是：<填：微信里的朋友/客户、各类渠道的陌生人、苹果手机用户>。我的预算是：<填：0元/愿意每年花99美元>。我有没有Mac：<有/没有>。
3. 针对PWA、微信小程序、iOS App三条路，各给出：是否适合我、最小可行版本只做哪一个功能、预计要重写多少、主要风险。
4. 给出你的推荐，并说明如果推荐PWA，做完以后什么情况下才值得再做另外两条。
```

你会看到：AI给出三条路的对比和一个明确推荐，没有改文件。

如果看到别的：AI给的建议是「全做」，让它限定「只选一条，只做一个功能」。

### 第2步（路线A）：把网页做成PWA

适合：几乎所有人，第一次都建议先做。

做法：给网站加一份manifest（应用名、图标、启动页面、显示方式），并确保是HTTPS。Next.js官方文档的写法是在`app/manifest.ts`里导出配置，包含名称、`display: 'standalone'`、颜色和192与512两种尺寸的图标。Vercel部署自带HTTPS。

```prompt复制给Claude Code或TRAE
请把这个Next.js项目做成可以「添加到主屏幕」的PWA。先说计划，等我确认。
要求：
1. 先读Next.js官方PWA指南（nextjs.org/docs/app/guides/progressive-web-apps）和本项目所装版本对应的文档，按官方方式在app/manifest.ts里写manifest。
2. 应用名和简称用我的作品名；display用standalone；主题色和背景色从现有页面配色里取。
3. 图标需要192×192和512×512两种尺寸PNG。如果我没有图标，请告诉我用什么办法生成，再把生成好的文件放到public目录。不要自己编造图片。
4. 暂时不做离线缓存和推送，除非我另外要求。
5. 完成后，告诉我如何在电脑上用浏览器开发者工具检查manifest有没有被识别，以及在iPhone上怎么安装。
验收标准：部署后，iPhone上从Safari能把它添加到主屏幕，点图标打开时没有浏览器地址栏。
```

部署后，在iPhone上用Safari打开你的网址：点页面菜单里的分享按钮，向下找到「添加到主屏幕」，点「添加」。苹果官方说明里还有一个选项叫「作为网页App打开」，让网站像App一样使用。这个图标只出现在你添加它的这台设备上。

你会看到：桌面多了你的图标，点开后全屏显示，没有地址栏。

如果看到别的：

- 没有「添加到主屏幕」选项：苹果官方说明可以在分享菜单底部「编辑操作」里把它加入列表。
- 图标是网页截图而不是你的图标：图标文件没被识别，让AI检查manifest路径和尺寸。
- 点开是空白：见[页面白屏](/fix/blank-page)。
- 国内手机打不开网址：见[Vercel在国内打不开](/fix/vercel-blocked-in-china)，PWA依赖网址能访问，这是它在国内的先天问题。

### 第3步（路线B）：做微信小程序

适合：用户在微信里，且你愿意把功能重写一遍。

注册和工具部分要你自己做。

1. 在微信公众平台（mp.weixin.qq.com）注册小程序账号。主体类型有个人、企业（含个体工商户）、政府、媒体、其他组织。个人主体不能做微信认证。
2. 注册完成后，在后台「设置-开发设置」里找到AppID（本站词典的说法，界面位置以微信后台为准）。
3. 下载安装微信开发者工具，用微信扫码登录。

然后让AI写第一个版本。只做一个不联网的小功能，先把全流程跑通：写、预览、上传、审核、发布。

```prompt复制给Claude Code或TRAE
我要做一个微信小程序，功能是：<填一个不联网的小功能，例如「记录每天喝水量并显示本周统计」>。我是个人主体，没有营业执照。
请先不要写代码，先做三件事：
1. 去微信官方开发文档（developers.weixin.qq.com/miniprogram）读一遍项目结构和数据存储的写法，告诉我你打算用原生写法还是某个框架，并说明理由。
2. 列出个人主体做这个小程序可能被限制的地方，哪些是你在官方文档里确认的，哪些你不确定。
3. 告诉我需要我手动做的步骤：填AppID、导入微信开发者工具、真机预览。
这个版本只用小程序自带的本地存储，不请求任何外部服务器，不涉及支付。
我同意方案后你再生成项目。小程序不能用window、document这些浏览器的东西，别照搬网页代码。
```

你会看到：AI给出方案和三个要你手动做的步骤。

确认后，把项目目录用微信开发者工具导入，填入你的AppID，点预览，用微信扫码在真机上看。

如果看到别的：

- 提示AppID无效或不匹配：见[AppID问题](/fix/miniprogram-appid)。
- 开发者工具里正常、真机上请求失败：多半是域名问题，见[合法域名问题](/fix/miniprogram-domain)。这也解释了为什么本关这个版本不联网：请求你自己服务器的域名要配成合法域名，需要HTTPS，通常还需要备案。第4关用的Supabase域名不是你备案的，能不能配成合法域名我没有核实，建议先别指望，需要联网的话优先考虑国内的后端服务。

功能能在真机预览后，在开发者工具里上传代码，到微信后台提交审核。官方说明审核通过后需要你手动点击发布才会上线。类目选错或功能和类目不符，会被拒。

你会看到：后台出现审核中的版本，通过后你点发布，微信里能搜到或扫码打开。

如果看到别的：被拒了，把拒绝原因原文给AI，让它告诉你改什么，然后重新提交。

### 第4步（路线C）：做iOS App

适合：有Mac，想做长期正式产品，愿意每年付99美元。

准备工作：

1. 在苹果开发者网站（developer.apple.com/programs）加入Apple Developer Program，年费99美元，在提供当地货币的地区按当地货币（官方页面，2026年11月）。个人开发者要用真实姓名，这个名字会显示为App Store上的卖家名。以公司名义要有D-U-N-S编码、公司域名邮箱和可访问的官网。账号身份选错后期转换麻烦，想清楚再注册。
2. 在Mac上安装Xcode。

同样先做一个不联网的小版本，打通流程。

```prompt复制给Claude Code或TRAE
我要做一个iPhone App，功能是：<填一个不联网的小功能>。我有Mac，已装Xcode，还没注册开发者账号。
请先不要写代码，先做四件事：
1. 推荐用SwiftUI还是别的方式，说明理由，并告诉我项目怎么建、在模拟器和真机上怎么跑。
2. 列出从写完到上架要经过的步骤：真机测试、TestFlight内测、App Store Connect填写、提交审核，每一步需要我手动做什么。
3. 查App Review Guidelines，告诉我这个功能最可能被拒的三点，以及上架必备的东西（隐私政策网址、测试账号、截图尺寸等）。
4. 明确告诉我哪些步骤需要付费账号才能做，哪些不需要，不确定的就说不确定，并给官方页面网址。
我确认后你再生成项目。App不能是网页的壳，要有真正的原生界面。
```

你会看到：AI给出路线和上架步骤清单，并标出需要付费账号的环节。

之后你按清单做：在Xcode里运行到模拟器、连接真机运行，再上传到App Store Connect，通过TestFlight邀请自己和朋友内测。

如果看到别的：

- Xcode提示签名错误：见[签名问题](/fix/xcode-signing)。
- 提交审核后被拒：见[审核被拒](/fix/app-review-rejected)，逐条对着拒绝原因改。
- 想上架中国大陆区：还涉及App备案，见[备案](/words/icp-filing)。

苹果的审核时长没有固定数字，别把对外发布日期卡死。

## 验收：怎么知道真的成了

- PWA：iPhone桌面有图标，点开全屏，没有地址栏；换成4G也能打开。
- 小程序：真机预览能正常用；已提交审核，或者已发布，并能扫码打开。
- iOS App：在你自己的iPhone上通过TestFlight或开发运行能打开；已经知道上架还缺哪几项。
- 你能说出自己为什么选了这一条，没选另外两条。
- 项目里没有新提交的密钥或证书文件。

## 最常卡在这几个地方

- 小程序开发者工具里正常、真机报错：见[合法域名问题](/fix/miniprogram-domain)。
- AppID填错或和账号不对应：见[AppID问题](/fix/miniprogram-appid)。
- Xcode编译通过却装不上真机：见[签名问题](/fix/xcode-signing)。
- 审核被拒：见[审核被拒](/fix/app-review-rejected)。
- PWA打开空白：见[页面白屏](/fix/blank-page)。
