```error
This site can't be reached
xxx.vercel.app took too long to respond.
ERR_CONNECTION_TIMED_OUT
```

## 人话：这是怎么回事

你的网站在你自己的网络下正常，但国内的朋友打不开或者很慢。这不是你的代码问题。

Vercel官方的说明是：它在中国大陆没有服务器和CDN节点，访问要绕远路，所以延迟高；同时国内的网络管控可能限制或降速对境外域名的访问，**官方原话点名包括 `.vercel.app` 子域名**。是否被限制因域名、运营商、时间而异，Vercel自己也说无法保证大陆的可用性和性能。

```prompt 复制给 Claude Code
3. 不要给出任何绕过网络监管的方法。
```

## 想自己动手的话

按风险从低到高，有这几个合规的选择：

1. **自定义域名。** 把 `vercel.app` 换成你自己买的域名（绑定方法见 [domain-not-working](/fix/domain-not-working)）。Vercel称自定义域名「被限制的可能性更低，但没有哪个域名是免疫的」，所以这只是缓解，不是保证。
2. **自托管关键资源。** 字体、统计脚本、图标尽量放在自己站点，别依赖 Google Fonts 这类可能被限制的服务。
3. **面向大陆用户，选国内平台。** 把站点放到国内云服务商（阿里云、腾讯云等）。网站使用大陆服务器并绑定域名对外提供服务，需要完成 [ICP备案](/words/icp-filing)，由云服务商引导提交，审核需要时间，具体规则以工信部和服务商最新要求为准。
4. **两个站点。** 国内一个、海外一个，Vercel官方也提到有客户这样做。在国内托管同样需要备案。

> [!warn] 网上有教你用各种「加速」「翻墙」手段让Vercel在国内直连的方法，既不稳定，也可能违反规定，这里不提供。Vercel官方也不推荐在它前面再套代理。

## 下次怎么避免

项目开始前先想清楚用户在哪。目标是海外用户，Vercel很合适；目标是大陆用户，从一开始就按国内平台加备案规划，比上线后再迁移省事。

## 还不行？

先确认是不是只有你的网络有问题：换手机流量、请不同城市的朋友试一试。[CDN](/words/cdn) 和备案的基本概念可看词典。涉及备案的具体流程，以你所选云平台的官方指引为准。
